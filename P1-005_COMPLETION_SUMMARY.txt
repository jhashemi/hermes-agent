4. INSTANCEORCHESTRATOR INTEGRATION
   ────────────────────────────────

   Flow:
   1. Verify API key using verify_api_key()
   2. Validate request (agent_id, prompt, length)
   3. Call orchestrator.execute_on_instance(agent_id, prompt, session_id)
   4. If returns None (local instance), fall back to gateway_runner.agent.chat()
   5. Build response with status, output, error, timestamp
   6. Return JSON response
   
   The orchestrator handles:
   - Instance resolution (local vs remote)
   - HTTP calls for remote instances
   - Retry logic with exponential backoff
   - Error classification (auth, timeout, server errors)
   - Connection pool management
   
   Location: remote_agent_api.py, lines 142-177


5. ERROR HANDLING
   ──────────────

   Auth Failures (401):
   - Invalid API key
   - Missing API key header
   - Unconfigured API key
   → Logged at WARNING level
   → Returns 401 Unauthorized
   
   Validation Errors (400):
   - Empty agent_id
   - Empty prompt
   - Prompt exceeds max length
   → Logged at WARNING level
   → Returns 400 Bad Request
   
   Execution Errors (500):
   - Instance not found
   - Orchestrator unavailable
   - Timeout/network errors
   - Other exceptions
   → Logged at ERROR level
   → Returns 500 Internal Server Error
   → Error message truncated to 500 chars
   
   Location: remote_agent_api.py, lines 178-195

CONFIGURATION
================================================================================

Environment Variables:

export HERMES_REMOTE_API_KEY="your-secret-key-here"

This enables API authentication. Without it, the endpoint will reject all requests
with 401 Unauthorized.


Integration with Gateway:

from gateway.instance_orchestrator import InstanceOrchestrator
from gateway.remote_agent_api import create_remote_api_blueprint

# Initialize orchestrator
orchestrator = InstanceOrchestrator()
await orchestrator.init()

# Make available to gateway
gateway_runner.instance_orchestrator = orchestrator

# Register endpoints
await create_remote_api_blueprint(app, gateway_runner)
